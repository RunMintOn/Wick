# 这个工具是做什么的

一个 macOS 小工具，用来照看你自己电脑上那些一直在后台跑的服务。

## 它解决什么问题

你在本机上会装一些常驻的小程序：一个自己记笔记的服务、一个博客的预览、一个本地
的图片处理工具。它们不像普通软件那样打开就出现窗口，而是安静地在后台跑着，你通过
浏览器访问。

问题是，你并不总是知道它们的状态。电脑重启之后它们可能没起来；某个进程可能半夜自
己挂了；也可能你想临时关掉其中一个。平时没有地方看，只有等到要用的时候发现打不
开，才知道出了问题。

这个工具就是那个地方。它把这些服务列在一起，每个服务旁边有一个状态点：绿的是还在
跑，灰的是停了，红的是出错退出了。点开能看到进程号、CPU、内存占用、访问地址和退出
码，也能直接启动、停止、重启、看日志。

## 它不是什么

- **不是 Docker 或虚拟机的管理界面。** 它管的是直接跑在你 Mac 上的原生进程，没有容
  器，没有 Linux 虚拟机，不额外吃那一层内存。
- **不是应用商店，也不负责安装。** 下载和安装服务由你自己完成，这个工具只负责登记之
  后怎么跑。
- **不是开机自启的总开关。** 「登录时启动」是针对每个服务单独设置的，改这个设置不影
  响服务当前的状态；手动启停也不改变这个设置。
- **不是后台管理器本身。** 你关掉窗口，服务继续跑。窗口只是用来查看和操作的。

## 日常怎么用

左侧列出所有已登记的服务，右侧是选中服务的详情。

- 顶部的指示器显示和后台管理器的连接状态：已连接、连接中、不可用。这个状态说的是能
  不能和后台通信，不表示所有服务都健康，配置有错也不代表连接断了。
- **启动 / 停止 / 重启 / 查看日志** 是四个基本操作。
- 服务有访问地址时，地址旁边会有一个「在浏览器打开」。
- **刷新** 重新读取状态。后台不可用时这个按钮会变成「重连」。

## 服务挂掉之后

服务意外退出时，会自动重试，默认 3 次，间隔 2 秒。这个次数是按该服务当前这次登记累
计的，不是滑动时间窗口。

次数用完就停了，不会无限重启。这时候看日志找原因，修好之后点「启动」会重新给一份新
的重试额度。

你主动停止的服务不算异常退出，不会触发自动恢复。

## 谁来登记服务

服务由 Agent 协助登记。你不需要记启动命令，只要让 Agent 读一下这个项目里的 Skill，
它知道怎么把一个已经装好的服务加进来，也知道怎么处理已经在跑的进程。

登记不包含下载和安装。唯一需要你手动编辑的文件是数据目录里的 `services.yaml`；
`runtime.yaml` 是生成的，不是另一份配置来源。

## 数据放在哪

所有状态都在你的用户目录下，一个文件夹里：

```
~/Library/Application Support/Wick
```

里面有服务配置、控制用的本地 socket、运行时的生成文件、日志和各个服务自己的数据。
删掉这个文件夹等于清空所有登记，服务本身不受影响。

## 技术上的选择

窗口用 Electron，进程管理用 Process Compose。选它们是因为在 macOS 上足够稳，而且不
需要引入容器那一层。

构建产物是本地未签名的 Apple Silicon 应用，不是公开发布的版本。它只替换自己生成的输
出目录，不动别的东西。

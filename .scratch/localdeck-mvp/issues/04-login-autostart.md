# 04: 登录自启开关

**What to build:** 登录自启开关，完成从用户或 Agent 操作到真实本机服务行为的闭环。范围以父 spec 为准，不增加新的平台或管理器。

**Blocked by:** 03

**Status:** resolved

- [x] 每个服务独立设置登录自启并写回唯一配置。
- [x] 修改开关不改变服务当前运行状态，手动启停不改开关。
- [x] 使用用户级 launchd 拉起后台，关闭自启的服务仍可手动启动。
- [x] 配置并发变更不会静默丢失字段。
- [x] 隔离测试启动项，记录真实登录验收的结果或未验证限制。

## Comments

已实现自启开关、带版本校验的 YAML 原子写入和用户级 launchd 集成。GUI E2E、配置冲突测试与真实隔离 launchd job 测试通过：后台由 launchd 直接管理，启动时只运行启用自启的服务，主进程无额外常驻 Node 包装。未退出当前用户会话，因此真实注销/重新登录尚未验证，不能把同会话 bootstrap 称为登录验收。测试启动项已 bootout，未安装正式自启项。

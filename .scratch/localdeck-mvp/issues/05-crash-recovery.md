# 05: 有限异常恢复

**What to build:** 有限异常恢复，完成从用户或 Agent 操作到真实本机服务行为的闭环。范围以父 spec 为准，不增加新的平台或管理器。

**Blocked by:** 02

**Status:** resolved

- [x] 异常退出后有限重试，达到上限后提示失败并提供日志。
- [x] 主动停止不会自动重启。
- [x] 修复后手动启动能开始新一轮尝试。
- [x] 验证子进程清理和重试计数范围，不自研额外调度器。

## Comments

已完成默认 3 次/2 秒有限恢复、日志提示和耗尽后的单服务恢复。真实测试验证偶发崩溃恢复、持续失败停止、修复后新重试预算、主动停止保持停止和父子进程清理。当前版本原生命令不重置耗尽计数，使用已有单服务更新接口重新登记该服务，并提供极小 recover 集成脚本；没有自研调度器。信号退出 -1 无法从管理器可靠区分手动停止与外部杀进程，界面明确展示该限制及预算提示。

最终恢复方式改为修改该服务的生成配置版本，并通过服务端 reload 触发仅该服务的重新登记。这样避开单服务 JSON 接口的数字类型差异；回归测试确认恢复后再添加服务也不改变原服务 PID。

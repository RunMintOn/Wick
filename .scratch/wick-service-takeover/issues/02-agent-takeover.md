**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 流程覆盖旧实例、端口、启动信息、数据、旧管理器和自启盘点。
- [x] 区分切换临时关闭与最终自启选择，不静默套用新服务默认值。
- [x] 失败不自动回切、不覆盖数据；确认旧实例退出、端口释放。
- [x] 收尾报告运行、自启与生效时机、旧管理器状态和其他服务 PID。

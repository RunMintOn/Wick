# 04: 单独操作组成进程与完整接管验收

**What to build:** 用户和 Agent 均可单独操作组成进程，操作明确体现依赖影响；Agent 能将多个旧登记接管为一个服务。

**Blocked by:** 02: Agent 接管保留自启意图与恢复依据；03: 多进程服务整体管理。

**Status:** resolved

- [x] 单独启动自动满足依赖；停止只停目标，运行中的依赖方存在时需确认。
- [x] 单独重启只重启目标并提示影响，不重启依赖或依赖方。
- [x] 控制台与 CLI 使用同一管理接口，状态、错误与日志可诊断。
- [x] Agent 文档覆盖不同旧自启状态汇总和最终选择。
- [x] 隔离验证多进程接管、部分失败、数据可用及无关服务 PID 保持。

验证：组成进程接口/CLI 测试通过；隐藏窗口 E2E 覆盖确认、取消和目标重启；临时旧进程接管测试验证端口冲突失败、退出后接管、SQLite 原记录保留与完整性、无关 PID 保持。旧管理器用临时进程模拟，未修改真实 launchd；没有执行真实注销登录。

# 03: 多进程服务整体管理

**What to build:** 一个服务展示多个组成进程及依赖，提供整体启停、重启和一个自启开关，启动等待依赖就绪，准确呈现部分失败并允许重试。

**Blocked by:** 01: CLI 结果与诊断清晰可判断。

**Status:** resolved

- [x] 现有单进程登记兼容，拒绝歧义归属、未知依赖和依赖环。
- [x] 控制台按服务展示，详情包含组成进程状态、PID、依赖和各自日志。
- [x] 启动等待就绪，失败阻止下游但不阻止独立分支，不回滚已有进程。
- [x] 重试只补齐缺失进程；运行故障不连带停止，整体反映异常。
- [x] 整体停止按逆序，失败后继续并报告残留。
- [x] 一个自启开关控制全部组成进程，下次后台启动执行依赖规则。
- [x] 隔离验证部分失败、后台重启、自启应用和未修改服务 PID 不变。

验证：6 个真实 Process Compose 集成场景通过；隐藏窗口控制台 E2E 通过；类型检查通过。自启依赖复用原生健康检查，未增加常驻编排进程。

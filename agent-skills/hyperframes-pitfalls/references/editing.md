# 编辑工程

## 预览工具会改写源码

**已观察：HyperFrames 0.8.216。** 开启预览后，HTML 被自动加入 `data-hf-id`；可视编辑还可能重新序列化属性和 JSON 引号。此前读取的整行标签不再匹配，补丁可能失败；这类变化本身不代表用户改了内容。

1. 编辑前按原有 history 流程检查变化，并重新读取受影响文件。
2. 保留当前 `data-hf-id` 和用户内容，围绕实际标签做局部修改。清掉工具标识可能破坏可视编辑器对元素的定位。
3. 补丁失败时先检查已完成操作，再读取未匹配部分；不要重复应用已经成功的修改。

**完成标准：** 目标改动已落到当前源码，已有标识与无关内容仍在；只复查受影响的镜头或行为。

## 参考原件被当成可编辑场景

**已观察：HyperFrames 0.8.216。** 仅借用部分代码的注册表组件原件仍放在 `compositions/` 下，预览编辑器将它列为额外场景，并显示其独立警告。一次 CLI 检查未报错，不能据此认定编辑器展示内容相同。

先区分两类文件：

- 实际挂载或被引用的组件：按 `hyperframes-registry` 的接线方式保留。
- 仅供追溯的原件：确认没有挂载、导入或相对资源依赖后，移到场景发现目录之外，例如 `references/`；保留来源说明。

**完成标准：** 预览中不再出现多余场景，实际使用的效果和资源仍能加载。不要为消除警告批量移动整个组件目录。

## 网页拆段后，只改一个时间会使其他部分失配

**已观察：HyperFrames 0.8.216。** 可视编辑器把同一子合成拆成多个宿主，后段通过 `data-playback-start` 继续读取同一份源时间线。用户移动了视觉片段后，工程中仍可能保留旧的音效时间、音乐淡出和根时长。不要假定这些关联项已自动对齐，也不要恢复拆段前的旧文件覆盖当前编辑。

1. 以当前源码和 history 为基准，在场景发现目录之外备份受影响文件。分别读取宿主的 `data-start`、`data-duration`、`data-playback-start`，以及子合成的 GSAP 时间。
2. 无变速时，`sourceTime = data-playback-start + (filmTime - data-start)`。后段不是从源时间零点重播；改共享源时间线也会影响其他实例。存在变速或其他映射时，按当前运行时规则核对，不套用这个简式。
3. 缩短推进动作、压缩停留、移动整段是不同修改。只改目标范围，保留其余实例的顺序和源偏移。
4. 同步关联音效、音乐自动化点与根 `data-duration`；以要保留的画面和声音终点确定总时长，而不是继续沿用旧片长。

**完成标准：** 拆点前后源时间连续；转场与声音落点匹配；实际导出的最后一帧和淡出正确。检查项因重复实例产生歧义时，转到 [选择器检查](verification.md#拆段后的同名元素使断言产生歧义)。

## 上一场景的标题叠在下一场景背景上

**已观察：HyperFrames 0.8.216 的重叠场景。** 新背景已进入，上一场景的高层级标题仍可见。这个现象不能直接证明合成器有缺陷；还要检查标题的退出时间和 stacking context。

先定位旧标题何时退场、两个宿主何时重叠，以及实际绘制层级。本次已验证的最小处理是让旧标题在新背景进入前淡出。若采用其他层级处理，应单独验证，不把它当作已验证的通用修复。

**完成标准：** 实际 MP4 在新背景进入前、进入中、进入后的解码帧均无非预期残留文字；不是只看两个场景各自的关键帧。

## 音频自动化在渲染时才报版本错误

**已观察：HyperFrames 0.8.216。** 简写的 `{"volume":[...]}` 使严格渲染报 `Unsupported automation version: undefined`。该工程换成以下结构后成功输出有声 MP4：

```html
data-automation='{"version":1,"lanes":[{"target":"volume","points":[{"t":0,"v":0.4},{"t":2,"v":0.8}]}]}'
```

遇到此错误时核对当前版本的 automation schema，再修正属性；不要绕过错误导出无声文件。其他版本以其 schema 和实际报告为准。

**完成标准：** 目标渲染成功，输出文件包含音轨，最终混音已测量。测量不等于试听。

## 局部样片通过，接入旧片后节奏仍断层

这是工作流经验，不是版本缺陷。先明确本轮要判断的是视觉方向、完整动作的节奏，还是整片衔接：关键帧不能证明速度感，只截高潮也不能证明开头起势。更换已有影片的开头时，局部方向通过后尽早粗拼原片检查前后节奏。

已有后段可用时，优先重剪停留、重复运镜和动作间隔，再对齐声音；不默认重做全片或整片倍速。方向未定时交付最小可评审样品，锁定后再做最终整片验收；继续沿用原 Skill 的必要检查，不因提速跳过它们。

**完成标准：** 样品覆盖范围明确，当前反馈针对该范围；不能把局部通过记录成整片节奏已通过。

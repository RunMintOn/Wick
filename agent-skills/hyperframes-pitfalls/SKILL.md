# HyperFrames 实战补充

本 Skill 保存已有 HyperFrames Skills 未覆盖的操作陷阱，不替代它们的创作、命令、素材与交付流程。按名称在当前环境定位相关 Skill，不依赖固定安装路径。

## 1. 选择分支

只读取当前任务需要的内容：

| 当前工作或现象 | 读取 |
|---|---|
| 预览后改稿、拆段或多余场景；转场残留文字；音频自动化报错 | [编辑工程](references/editing.md) |
| 运动断言未执行或误报；未来素材未加载；导出验证边界不明 | [验证是否有效](references/verification.md) |
| UI 取材缺失；完整窗口被误做成局部裁片 | [真实 UI 取材](references/capture.md) |

没有命中分支时，继续原有流程，无需为本 Skill 增加整片检查。

## 2. 用当前证据处理

版本相关行为先对照工程使用的 CLI 版本和实际报告，再采用对应处理。参考文件中的“已观察”限定了证据范围，不代表其他版本或平台必然如此。

针对命中的问题完成一次“确认现象 → 最小处理 → 复查”。保留能区分修复前后的证据；若当前环境不复现，就保留正常实现，不套用旧版本的处理方法。

## 3. 返回原流程

说明问题影响的画面或文件、采用的处理、实际完成的验证。验证未运行时明确指出，不能将“无报错”当成“已验证”。

修复成立的标准是：原问题在对应画面、时间点或检查项上已经消失。后续制作和交付仍按原有 HyperFrames Skills 与用户约定进行。

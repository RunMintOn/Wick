# 验证记录

## 范围

首版完成结构检查、实战证据核对和同一上下文内的场景推演；后续增补沿用此验证范围。没有启动无上下文的独立 Agent，也没有测量触发准确率或与原 Skills 的 A/B 差异；以下是人工审阅记录，不是模型行为基准测试。

`scenarios.json` 保存输入提示和预期行为，可在后续独立会话中复用。届时先只提供提示、正常的 Skill 发现入口和必要环境，再用预期行为评判输出，避免将答案一同喂给被测 Agent。

## 首版实战依据

核对了本次 HyperFrames 0.8.216 的现有产物：

- 运动验证报告从 `enabled: false, samples: 0` 变为根断言文件下的 `enabled: true, samples: 300`。
- 源码保留了预览工具加入的 `data-hf-id`。
- 采集记录包含状态条处理前后的计算样式，证明透明状态来自未完成的有限动画。
- 预览播放记录显示未来图标在展示前尚未加载、进入场景后正常；按当前展示范围验证的播放检查通过。

这些观察用于核对文档中的事实，不代表本轮重新执行了渲染或跨平台实验。操作系统相关结论仅放在取材参考中。

## 增补依据与边界

- 已对照同版本工程的保留记录：网页拆段包含源偏移；选择器先报歧义，限定实例后最终运动检查实际执行。
- 已结束场景被跨全片 `keepsMoving` 误计静止的记录，与最终采用的验证边界一致；不据移除断言宣称该项自动验证通过。
- 音频记录包含 `Unsupported automation version: undefined`，采用 version/lanes 后有声渲染成功。
- 项目交付物、具体素材来源和未决数据保留在工程自己的入口及阶段复查中；Skill 不复制它们，也不依赖原工程路径运行。
- 本次增补不重新执行渲染或跨平台实验，也不把中心遮罩的视觉选择归因为未隔离证明的 CSS/渲染器缺陷。网页导出仍未实际验证。

## 增补静态检查

- frontmatter、Markdown 围栏、空白、21 个相对链接及锚点检查通过。
- `scenarios.json` 有 16 个唯一场景记录；这是结构校验，不是执行了 16 次 Agent 行为测试。
- Skill 未引入本机绝对路径、固定预览端口、原工程依赖或运行脚本。
- 根 AGENTS 可到达 Skill 和项目工程入口；最终交付物的存在、大小与保留的 probe 记录一致。视频、时间线与音频未因知识整理而修改。

## 首版表达与维护审阅

- `skill-creator` 用于确定内容、编写首版和设计场景；`writing-for-agents` 用于审查触发入口、按分支披露、完成标准与精简，没有重复执行两套创作流程。
- 入口只路由到所需参考，不重复故事设计、命令手册或交付流程。
- 本机路径、固定端口、浏览器缓存位置和业务服务名称均未写入运行指令；没有新增脚本、运行依赖或安装动作。
- 目录置于 `agent-skills/`，避免被本仓库现有的 `skills/` 整体打包规则带入产品；根 `AGENTS.md` 只增加一条条件入口。
